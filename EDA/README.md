# EDA Projects

This folder contains hands-on EDA projects using Pandas, Matplotlib and Seaborn.

## Projects
- [Online Retail EDA](Online_Retail_EDA.ipynb) — Online Retail II (2009–2010). See [project notes](Online_Retail_EDA_README.md).
- [Used Car EDA](Used_Car_EDA.ipynb) — listed-price analysis by brand, fuel type, manufacturing year, mileage and city. See [project notes](Used_Car_EDA_README.md).

Dataset sources, steps, key findings and limitations are documented in each project's README.
