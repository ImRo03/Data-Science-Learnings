# Number Guessing Game

This is a simple Python number guessing game.

The computer generates a random number and I have to guess the number.

## How It Works

- The computer generates a random number between 1 and 30.
- I enter my guess.
- If my guess is lower than the number, it tells me to guess higher.
- If my guess is higher than the number, it tells me to guess lower.
- The game continues until I guess the correct number.

## Concepts Used

- `import`
- `random`
- `random.randint()`
- `input()`
- `int()`
- `while` loop
- `if / else`
- Comparison operators
