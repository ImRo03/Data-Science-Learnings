# Seaborn Practice

This is where I practiced Seaborn using the Shopping Trends dataset. I added notes and examples while learning the plots, then practiced choosing the right chart for a question.

## What I Practiced

- Scatter plots and line plots
- Using `hue`, `style`, and `size`
- Count plots and bar plots
- Box plots, violin plots, strip plots, and swarm plots
- Histograms, KDE plots, and ECDF plots
- Regression plots
- Heatmaps and correlation
- Pair plots and joint plots
- Filtering data with Pandas before plotting
- Using `groupby()` to compare groups
- Adding titles, axis labels, and adjusting figure size

## Practice Approach

I tried to understand the question first, choose the columns needed, select a suitable chart, and then explain what the chart showed. The final exercises combine filtering, grouping, plotting, and chart formatting.

## Notebook

The notebook for these notes and exercises is [Seaborn.ipynb](Seaborn.ipynb).
